## What This Project Is

SAP SFLIGHT data model (airlines, flights, bookings, passengers) as a modern **SAP CAP CDS** application with a **built-in MCP server** (19 tools). It demonstrates three ways to interact with SAP data through AI:

| Demo Path | Transport | Audience | Works Locally? |
|-----------|-----------|----------|----------------|
| **1. Claude Code (CLI)** | stdio (MCP) | Developers, power users | Yes |
| **2. OData Service Endpoint** | HTTP REST | API consumers, apps | Yes |
| **3. Claude for Excel** | HTTP/SSE (MCP) | Business users | Only when deployed (or via supergateway locally) |

## Quick Start — The 1-2-3

> **Prerequisite:** Node.js 18+ and `@sap/cds-dk` installed globally.
> If not: `nvm install 22 && npm install -g @sap/cds-dk`

### macOS / Linux / WSL2

```bash
# Step 1: Clone and install
git clone https://github.com/MindsetConsulting/sflight-mcp.git
cd sflight-mcp
npm install

# Step 2: Build the MCP server
cd mcp-server && npm install && npm run build && cd ..

# Step 3: Start the CAP server
cds watch
# Open http://localhost:4004 — 26 entities, 4 views, 24 CSV files loaded
```

**Or run the one-shot setup:** `bash scripts/setup.sh`

### Windows (PowerShell)

```powershell
# Step 1: Clone and install
git clone https://github.com/MindsetConsulting/sflight-mcp.git
cd sflight-mcp
npm install

# Step 2: Build the MCP server
cd mcp-server; npm install; npm run build; cd ..

# Step 3: Start the CAP server
cds watch
```

**Or run the one-shot setup:** `powershell -ExecutionPolicy Bypass -File scripts\setup.ps1`

> Both setup scripts install dependencies, build the MCP server, and create `.mcp.json` automatically.

That's it. OData is live. MCP tools are built. You're ready to demo.

### Adding Claude Code (AI-Powered Queries)

```bash
# Install Claude Code (one-time)
npm install -g @anthropic-ai/claude-code

# Create MCP config (tells Claude where the tools are)
# Run this from the project root:
node -e "
const p = require('path').resolve('mcp-server/build/index.js');
const c = {mcpServers:{'cap-tools':{command:'node',args:[p]}}};
require('fs').writeFileSync('.mcp.json', JSON.stringify(c, null, 2));
console.log('Created .mcp.json pointing to:', p);
"

# Launch Claude Code
claude
```

Now ask: *"Which airlines fly to London?"* — Claude will use MCP tools to query real data.

## Data Model (26 Entities + 4 Views)

| Category | Entities |
|----------|----------|
| Airlines & Fleet | Carriers, CarrierPlanes, Planes, CargoPlanes, PassengerPlanes |
| Routes & Flights | Connections, Flights |
| Bookings | Bookings, Tickets, Invoices |
| Customers | Customers, BusinessPartners |
| Travel | TravelAgencies, Counters |
| Airports | Airports, CityAirports, GeoCities |
| Meals | Meals, MealTexts, Menus, FlightMeals, Starters, MainCourses, Desserts |
| Currency | CurrencyRates, CurrencyDecimals |
| **Views** | FlightSchedule, BookingDetails, CarrierConnections, CustomerBusinessPartners |

**Key relationships:** Carriers → Connections → Flights → Bookings → Tickets/Invoices
**Seed data:** 24 airlines, ~5K flights, 10K+ bookings, 15+ cities, 73 aircraft types

## MCP Server — 19 Tools (cap_ prefix)

| Category | Tools |
|----------|-------|
| Model introspection | `cap_entities`, `cap_entity_detail`, `cap_associations`, `cap_nav_map`, `cap_services` |
| Schema & compile | `cap_compile`, `cap_edm` |
| Data queries | `cap_cql_query`, `cap_data_stats`, `cap_sample_data`, `cap_db_schema` |
| Analytics | `cap_data_distribution`, `cap_yoy_growth` |
| Project mgmt | `cap_csv_inspect`, `cap_project_info`, `cap_mta_info`, `cap_build`, `cap_hana_mapping` |
| Live OData | `cap_query` (requires running `cds watch`) |

**Execution model:** In-process CDS compile (cached 60s) + shell-spawned SQLite query runner.

## Commands Reference

### Daily Development

```bash
cds watch                        # Start local server (SQLite, auto-reload)
npm start                        # Start server (no auto-reload)
claude                           # Launch Claude Code with MCP tools
```

### MCP Server

```bash
cd mcp-server && npm run build   # Compile TypeScript → build/
cd mcp-server && npm run dev     # Watch mode (auto-recompile)
```

### BTP Deployment

```bash
npx cds build --production       # Generate db + srv artifacts
mbt build                        # Create .mtar archive
cf deploy mta_archives/sflights-mcp_1.0.0.mtar  # Deploy to CF
```

### HANA Hybrid Mode (local server → remote HANA)

```bash
# Option A: cds bind (recommended — no files to manage)
cds bind --to sflights-mcp-db:sflights-mcp-db
cds watch --profile hybrid

# Option B: default-env.json (manual — see README for format)
cds watch --profile hybrid
```

### hana-cli MCP (Direct HANA Access)

When deployed and HANA credentials are available, add hana-cli to `.mcp.json`:

```json
{
  "mcpServers": {
    "cap-tools": {
      "command": "node",
      "args": ["<PROJECT_ROOT>/mcp-server/build/index.js"]
    },
    "hana-cli": {
      "command": "node",
      "args": ["<HANA_CLI_PATH>/mcp-server/build/index.js"],
      "env": {
        "HANA_HOST": "<host>.hanacloud.ondemand.com",
        "HANA_PORT": "443",
        "HANA_USER": "<user>",
        "HANA_PASSWORD": "<password>",
        "HANA_ENCRYPT": "true",
        "HANA_SSLVALIDATECERTIFICATE": "true"
      }
    }
  }
}
```

To find hana-cli path: `npm list -g hana-cli --parseable`

**Simpler alternative:** If you have `default-env.json` (from `cds bind` or manual), hana-cli reads it automatically:

```json
{
  "mcpServers": {
    "hana-cli": {
      "command": "npx",
      "args": ["-y", "hana-cli", "mcp-server"]
    }
  }
}
```

| Endpoint | Description |
|----------|-------------|

## Three Demo Paths — Detailed

### Demo 1: Claude Code (CLI) — Developer / Power User

**What it shows:** Ask questions in plain English, get answers from real data via MCP tools.

```
You: Which airlines have the highest seat occupancy?
Claude: [uses cap_db_schema → cap_cql_query → formats answer]
       Top 5 airlines by average occupancy:
       1. Singapore Airlines (SQ) — 87.3%
       2. Lufthansa (LH) — 84.1%
       ...
```

**Setup:** Follow Quick Start above. Requires Claude Code + Anthropic API key.

### Demo 2: OData Service Endpoint — API Consumer

**What it shows:** Standard REST/OData V4 API that any app or tool can consume.

```bash
# List airlines
curl http://localhost:4004/odata/v4/flights/Carriers

# Flights with pagination
curl "http://localhost:4004/odata/v4/flights/Flights?\$top=5&\$select=CARRID,CONNID,FLDATE,PRICE,CURRENCY"

# Full flight schedule (denormalized view — joins carrier, route, plane)
curl "http://localhost:4004/odata/v4/flights/FlightSchedule?\$top=10"

# Carriers with their routes expanded
curl "http://localhost:4004/odata/v4/flights/Carriers?\$expand=CONNECTIONS"
```

**Setup:** Just `cds watch`. No Claude, no MCP needed.

> **Note:** OData V4 is great for entity-level CRUD, filtering, and navigation.
> For analytics (GROUP BY, aggregations, year-wise counts), use Demo 1 (MCP/Claude Code)
> which has `cap_cql_query`, `cap_data_distribution`, and `cap_yoy_growth` tools.

### Demo 3: Claude for Excel — Business User

**What it shows:** Business users query SAP data from Excel using natural language.

**Local testing (via supergateway):**
```bash
bash scripts/start-mcp-sse.sh
# → HTTP/SSE at http://localhost:8080
# Register in Claude org settings → Connectors → Add Custom Connector
```

**Production (BTP deployed):**
- The `@gavdi/cap-mcp` plugin exposes `/mcp` endpoint alongside OData
- Register `https://<approuter-url>/mcp` as Claude connector
- Business users open Excel → Claude add-in → ask questions

## Coding Conventions

- **CDS entity names:** PascalCase (e.g., `TravelAgencies`)
- **CDS field names:** UPPERCASE (e.g., `CARRID`, `CONNID`) — follows SAP SFLIGHT tradition
- **Service path:** `/odata/v4/flights`
- **MCP tool prefix:** `cap_` (all 19 tools)
- **MCP server language:** TypeScript (compiled to JS)
- **CAP handlers:** JavaScript (.js, not .ts)
- **Profiles:** `default` (SQLite), `hybrid` (local+HANA), `production` (HANA+XSUAA)

## Important Files (Do Not Delete)

| File | Why |
|------|-----|
| `.mcp.json` | Machine-specific MCP config (gitignored — each dev creates their own) |
| `default-env.json` | HANA credentials for hybrid mode (gitignored — never commit) |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `cds: command not found` | `npm install -g @sap/cds-dk` |
| MCP tools not showing in Claude | Check `.mcp.json` exists and path is absolute |
| `Cannot find module` in MCP server | Run `cd mcp-server && npm run build` |
| HANA connection fails (hybrid) | Run `cds bind` first, or check `default-env.json` |
| hana-cli can't connect | Ensure `default-env.json` has valid HANA credentials |
| Port 4004 in use | macOS/Linux: `lsof -i :4004` then `kill <PID>`. Windows: `netstat -ano \| findstr :4004` then `taskkill /PID <PID> /F` |
| SQLite errors | Delete `*.db` files in project root, restart `cds watch` |
| Claude Code on Windows | Claude Code requires WSL2. Install WSL2: `wsl --install` then run `claude` from WSL terminal |
| PowerShell script blocked | Run: `powershell -ExecutionPolicy Bypass -File scripts\setup.ps1` |
